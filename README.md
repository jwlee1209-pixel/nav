# 길잡이 내비

무료 지도(OpenStreetMap)로 길을 찾고 한국어 음성으로 안내하는 개인용 내비게이션(차량·도보). HTML 파일 하나로 동작한다.

## 쓰는 법
- PC: `dist/길잡이내비_v버전.html` 을 크롬·엣지로 연다. 위치 권한을 허용하면 현재 위치에서 출발한다. 위치가 없으면 출발지를 직접 고르고 ‘모의 주행’으로 안내를 미리 들을 수 있다.
- 휴대폰: 위치(GPS)·화면 꺼짐 방지는 https 주소에서만 동작한다(내려받은 파일로 열면 브라우저가 위치를 막는다). GitHub Pages 주소 **https://jwlee1209-pixel.github.io/nav/** 로 연다(저장소 jwlee1209-pixel/nav 의 `docs/` 폴더를 Pages 로 공개). 다른 웹사이트에 올릴 때는 `dist/길잡이내비_v버전_웹용.zip` 의 `navi` 폴더를 올린다. 홈 화면에 추가하면 주소창 없이 앱처럼 열린다(manifest.json·sw.js·아이콘 포함).
- HTML 은 빌드할 때 영문(ASCII) 문자만 쓰도록 바꿔, 서버가 EUC-KR 로 알려 줘도 한글이 깨지지 않는다.
- 저장 데이터(집·회사·즐겨찾기·즐겨찾는 경로·설정·주행 기록·지나간 길)는 그 브라우저에만 남는다. 설정 > 데이터에서 백업 파일로 옮긴다.

## 기능
- 검색: Photon(komoot) + Nominatim. 검색 버튼을 누를 때만 요청(자동완성 없음), 결과 7일 캐시, 서비스별 초당 1회 이하. Photon 은 `lang=default`(현지 = 한국어 이름)로 요청한다 — 비워 두면 브라우저 언어 목록에서 영어를 골라 영문 이름·주소를 준다(v1.6까지의 문제). v1.7 은 예전에 영문으로 저장된 최근 목적지·즐겨찾기·주행 기록 이름을 처음 한 번 한국어로 다시 찾아 고친다(같은 장소를 못 찾으면 이름은 두고 주소만 좌표로 다시).
- 검색어 줄이기: OSM 에 그대로 없는 이름·주소는 차례로 줄여 다시 찾는다 — 붙여 쓴 아파트 이름(‘가온누리타운2차아파트’ → ‘가온누리타운2차’ → ‘가온누리타운 2차’ → ‘누리타운 2차’ → ‘누리타운’(근처 50km 안만)), 번지까지 쓴 주소(건물 번호가 OSM 에 없으면 길 위치). 어떤 검색어로 찾았는지 결과 위에 한 줄로 알려 준다.
- 주소·건물 검색(선택, v1.8): 설정 → 주소·건물 검색에 브이월드(국토교통부 공간정보 오픈플랫폼) 무료 인증키를 넣으면 OSM 보다 먼저 브이월드 검색 API 2.0(주소처럼 보이면 도로명 → 지번 주소, 아니면 장소 이름)과 지오코더 2.0(좌표 → 도로명 주소)을 JSONP 로 부른다. 키 발급 때 서비스 URL 은 앱 주소의 도메인(https://jwlee1209-pixel.github.io), 요청의 domain 값도 그 주소. 키는 그 브라우저에만 저장(백업 파일에는 포함). 키가 틀리면 브이월드가 준 이유를 검색 결과 위에 보여 주고 OSM 결과만 쓴다.
- 현재 위치 저장(v1.9): 첫 화면·내 장소의 ‘현재 위치 저장’ → GPS 위치(15초 안의 것, 없으면 최대 10초 기다림)와 주소·정확도를 보여 주고 이름·메모를 받아 즐겨찾기(또는 집·회사)에 저장. 이름 칸은 그 자리 주소 이름으로 미리 채움. 장소 카드의 ‘이름·메모’, 내 장소 화면에서 고친다.
- 내 장소 찾기: 검색창에 쓰면 집·회사·즐겨찾기·최근 목적지를 이름·메모·주소로 찾는다(띄어쓰기·대소문자 무시, 낱말 순서 무관). 검색 버튼을 눌러도 맞는 내 장소를 온라인 결과 위에 먼저 보여 준다.
- 도보 이동(v2.0): 경로 화면의 ‘차량 | 도보’로 바꾸고, 설정 → 기본 이동 방법으로 처음 값을 정한다. 도보는 Valhalla pedestrian(시속 4.5km, 계단 피하기 = step_penalty 600), 응답이 없으면 OSRM routed-foot. 카드에 걸음 수(0.7m/걸음)·회전·계단 수, 유류비·쉬운 길 추천·단속 카메라·속도계 없음. 안내는 100m 앞 + ‘잠시 후’(22m), 400m 넘는 직진 안내, 계단·엘리베이터·에스컬레이터·건물 출입(Valhalla 39~43) 안내, 이탈 판정은 더 너그럽게(정확도+15m, 6초 이상), 도착은 목적지 15m 안. 화면은 확대 18·기울기 35°, 모의 걷기 ×1·×4·×8. 차량 주행 기록·도로 학습은 도보 시간에 쓰지 않고, 도보 기록도 차량 보정에 쓰지 않는다.
- 아래 목록 끌기(v2.1): 목록(시트)은 접기(손잡이+한 줄)·보통·크게 세 크기. 손잡이나 목록 맨 위를 손가락으로 끌어 내리면 접히고 올리면 커진다(놓으면 가까운 크기, 빠르게 튕기면 그 방향으로 한 단계, 옆으로 밀기는 무시). 접힌 목록을 누르면 보통 크기, 손잡이를 누르면 보통↔크게. 같은 화면을 다시 그려도 손으로 맞춘 크기를 유지하고, 다른 화면으로 가면 그 화면의 기본 크기. PC 는 손잡이를 마우스로 끈다.
- 경로: Valhalla(FOSSGIS) 우선, 응답 없으면 OSRM(FOSSGIS). 옵션 추천/최단거리/무료도로/고속도로 회피, 경유지 3곳, 후보 경로 최대 3개.
- 안내: 다음 회전 표지판(일반도로 청색·고속도로 녹색), 시계 방향 표현(1시 방향 등), 고속도로 2km·1km·500m / 일반도로 1km·300m / ‘잠시 후’, 연속 회전 ‘이어서’, 긴 직진 안내, 경로 이탈 시 진행 방향을 반영해 재탐색, 경유지·도착 안내.
- 개인화: 내 주행 기록(시간대별 중앙값)으로 도착 시간 보정, 요일·시간대가 비슷할 때 자주 간 곳 추천, 연비·유가로 유류비 계산.
- 도로별 교통 학습: 안내 중 지난 구간(300m 이상, 이름 있는 도로)의 '실제 시간 ÷ 예상 시간'을 도로명·시간대(평일 출근·퇴근·낮, 밤, 주말)별로 지수 이동 평균(최근 30% 반영)해 저장하고, 경로 후보의 시간 계산·순위와 안내 중 남은 시간에 쓴다(2회 이상, 120일 이내 기록만).
- 운전하기 쉬운 길: ‘추천’에서는 Valhalla 에 회전 비용을 높인 경로(maneuver_penalty 30, use_distance 0.2 등, 빠른 길에 유료도로·페리가 없으면 그것도 피하게)를 한 번 더 요청해 비교. 난이도 점수 = 회전 가중합(좌회전 1.6·유턴 2.5·회전교차로 1.3 …) + 시속 30km 미만 구간 비율×20. 쉬운 길은 ① 난이도 점수가 20%·2점 이상 낮고 ② 거리가 빠른 길보다 25%(최소 1.5km) 넘게 길지 않고 ③ 빠른 길에 없던 유료도로·페리가 생기지 않아야 하며, ④ 늦어지는 시간이 기준 시간(기본 10분, 25분 미만 짧은 길은 빠른 길 시간의 40%·최소 3분) 미만일 때 추천한다. ②·③ 때문에 뺀 길은 그 이유를 한 줄로 보여 준다(v1.6: 11km 길 대신 25km 유료 경로가 ‘운전 쉬움’으로 추천되던 문제 수정).
- 단속 카메라: 경찰청·지자체 「전국무인교통단속카메라표준데이터」(공공데이터포털, 반년마다 갱신)를 `tools/cameras.py` 로 압축한 `src/web/cameras.json`(약 3만 대). 경로선 오른쪽 30m·왼쪽 9m 안의 카메라만 경로에 붙여 반대 차로 카메라를 줄이고, 고속도로 600m·일반도로 300m 앞 음성 안내, 구간단속 시작·끝과 구간 평균 속도, 어린이·노인 보호구역, 제한속도 초과 경고(+3km/h). 단속구분 코드는 공식 코드표를 확인하지 못해 1=과속, 2=신호, 1+2=신호·과속, 3·4(법규·주정차) 제외, 99+구간위치=구간단속으로 해석(자료 분포·다른 공개 프로젝트 해석과 일치). 자료 갱신: 새 파일을 받아 `python3 -I tools/cameras.py <파일> <기준일>` 후 빌드.
- 화면: 주간/야간 자동(해 고도), 진행 방향 위·3D 시점, 모의 주행(×1·×2·×4).
- 주행 기록·즐겨찾는 경로(v2.3)
  - 첫 화면 목록의 ‘주행 기록’ 탭: 실제 안내를 받은 주행(모의 주행 제외)을 날짜별(오늘·어제·11월 28일 (토))로 ‘출발지 → 도착지’, 출발 시각·거리·걸린 시간·지난 도로와 함께 보여 준다. 출발지 이름은 집·회사(250m)·즐겨찾기(250m)·최근 목적지(150m) 안이면 그 이름, 아니면 좌표→주소. 안내를 중간에 끝낸 주행도 남긴다(‘중간에 끝냄’).
  - 지나간 길: 안내 중 위치를 경로에 맞춘 점(경로를 벗어났을 때는 정확도 40m 이하 GPS 점만)으로 10m 마다 모았다가, 끝날 때 Douglas–Peucker(4m 허용)로 줄여 polyline(정밀도 5)으로 저장한다. 기본 저장 자료(`gilnavi.v1`)와 따로 `gilnavi.tracks.v1` 에 최근 80개 주행까지 둔다. 200m 미만 주행은 길을 남기지 않는다.
  - 기록을 누르면 지도에 지나간 길을 보여 주고 ‘이 경로로 안내’·‘즐겨찾는 경로로 등록’·‘이 기록 지우기’. v2.3 전에 남은 기록은 지나간 길이 없어 ‘도착지로 길 찾기’만 할 수 있다.
  - 이 경로로 안내: 기록한 길을 그대로 따라가는 경로를 Valhalla 에 지나는 점(`type: through`, 멈추거나 안내하지 않는 경유점)으로 요청한다. 길을 단순화해 꺾이는 곳마다 그 뒤 나가는 길 위 70m(다음 꺾임까지 절반 이하) 지점에 점을 두고 진행 방향(heading, 허용 ±60°)을 붙여 반대 차로·옆길로 붙지 않게 하며, 긴 직선은 2.5km 이상 간격으로 채운다(출발·도착 150m 안 제외, 최대 15곳 — 공개 서버의 지점 수 한도 안). 받은 경로가 기록과 92% 넘게 겹치지 않으면 다르게 간 구간 시작 조금 뒤에 점을 더 넣어 한 번 더 찾는다. 현재 위치가 기록한 길 중간이면 가장 가까운 곳부터 남은 길만 따라간다.
  - 경로 카드에 ‘기록한 길’ 표시와 겹친 비율(97% 이상은 ‘기록한 길 그대로’), 지도에 기록한 길을 회색으로 함께 그린다. 보통 길(빠른 길)도 함께 찾아 3분 이상 빠르거나 1km 이상 짧으면 두 번째 카드로 보여 준다. ‘보통 길로 찾기’로 언제든 바꾼다. 기록한 길을 못 찾으면 이유를 알리고 보통 길을 보여 주며, ‘다시 시도’로 다시 찾는다.
  - 안내 중 이탈: 기록한 길에서 2.5km 안이면 지나온 곳 뒤쪽은 빼고 기록한 길로 되돌아가게 다시 찾고, 더 멀리 벗어나면 ‘기록한 길에서 많이 벗어나 보통 길로 안내합니다’.
  - 즐겨찾는 경로: 이름(기본 ‘도착지 (첫 도로)’)·메모를 붙여 최대 30개. 첫 화면 칩(쓴 횟수 많은 순 4개)과 즐겨찾기 탭 맨 위에서 바로 안내, 연필 단추로 이름·메모 고치기·지우기. 주행 기록을 지워도 즐겨찾는 경로는 자기 길을 따로 가지고 있어 남는다. 백업 파일에 즐겨찾는 경로·지나간 길이 함께 들어간다.
- 홈 화면에 추가·카카오톡으로 보내기(v2.4)
  - 휴대폰에서 웹 주소로 열면 첫 화면 목록 맨 위에 ‘홈 화면에 추가’ 카드(× 로 60일 숨김, 설정 → 앱 정보에는 늘 있음). 홈 화면 앱으로 열었거나(display-mode standalone·navigator.standalone) 컴퓨터·내려받은 파일이면 보이지 않는다.
  - 크롬·엣지: `beforeinstallprompt` 를 받아 두었다가 카드 단추로 바로 설치 창. 아직 못 받았으면(첫 방문 등) 브라우저 메뉴 순서를 보여 준다 — 크롬 ⋮ → 홈 화면에 추가(또는 앱 설치) → 설치, 아이폰 공유(iOS 26 은 ⋯ → 공유) → 홈 화면에 추가 → 추가, 삼성 인터넷 ≡ → 현재 페이지 추가(없으면 도구 안) → 홈 화면.
  - 카카오톡 안 화면(UA 의 KAKAOTALK)에서는 홈 화면 추가가 안 되므로 `kakaotalk://web/openExternal?url=…?add=home` 로 휴대폰 기본 브라우저(아이폰은 Safari)를 연다. 옮겨 간 브라우저는 `?add=home` 을 보고 주소에서 지운 뒤 바로 안내 창을 띄운다. 2초 뒤에도 카카오톡 화면이 그대로면 ⋮ → 다른 브라우저로 열기(아이폰: 공유 → Safari)와 주소 복사를 보여 준다. 라인은 `openExternalBrowser=1`, 그 밖의 앱 안 화면(네이버·인스타그램 등, 안드로이드 웹뷰)은 메뉴 안내만(모르는 주소로 바꾸다 화면을 잃지 않게).
  - 앱 안 화면·Safari 와 홈 화면 앱은 저장 공간이 따로라, 저장한 것이 있으면 ‘옮겨지지 않으니 홈 화면 앱에서 등록하거나 백업 파일로 옮기라’고 알린다.
  - 설정 → 앱 정보 → ‘앱 주소 보내기’: 휴대폰 공유 창(카카오톡 등)으로 앱 주소를 보낸다(없으면 주소 복사). 홈 화면 앱에는 주소창이 없어서 필요.
  - 링크 미리보기: og:title·og:description(‘열어서 홈 화면에 추가를 누르면 앱처럼’)·og:image(`og-image.png` 1200×630, 길 안내 표지판 모양, `node tools/og.js`). 카카오톡은 미리보기를 한동안 저장해 두므로 예전 미리보기가 보이면 카카오 디벨로퍼스의 공유 디버거에서 캐시를 지운다.
- 같은 사이트의 다른 앱(v2.2): 서비스 워커는 `docs/` 바로 아래 파일(내비 화면·아이콘·카메라 자료)만 다루고, 하위 폴더는 건드리지도 캐시에 넣지도 않는다. v2.1 까지는 같은 주소 아래의 다른 페이지(예: `ppt/`)를 열면 그 화면을 내비 첫 화면 캐시에 덮어써, 인터넷이 끊겼을 때 내비 대신 그 화면이 나올 수 있었다. 새 판으로 바뀌는 순간 예전 캐시(gilnavi-v2.1)를 지우므로 이미 덮어쓴 것도 바로 고쳐진다.

## 같은 사이트의 PPT 편집기(옮김)
- PPT 편집기는 **https://jwlee1209-pixel.github.io/apps/ppt/** (저장소 `apps`)로 옮겼다(v1.3). `/nav/ppt/` 는 내비 범위(`/nav/`) 안이라, 내비를 설치한 휴대폰의 크롬이 PPT 편집기를 따로 설치하지 않고 공유 목록에도 넣지 않았기 때문이다.
- `docs/ppt/` 는 예전 주소에 남긴 판: 같은 편집기에 ‘새 주소로 옮겼습니다’ 안내를 띄운다(앱 id 는 예전 그대로 /nav/ppt/). 소스는 이 저장소의 `claude/ppt` 브랜치: `node build.js 1.3 --id /nav/ppt/ --moved https://jwlee1209-pixel.github.io/apps/ppt/ --pages <이 저장소>/docs/ppt`.
- 내비 빌드(`node build.js`)는 `docs/` 바로 아래 파일만 새로 쓰고 `docs/ppt/` 는 그대로 둔다.

## 개발
```
npm install
node build.js 2.4        # dist/길잡이내비_v2.4.html, dist/web/navi/, docs/(GitHub Pages, 하위 폴더 docs/ppt 는 그대로), 웹용 zip
node test/unit.js        # 경로 정규화·안내 문구·안내 엔진·개인화
node test/unit-history.js  # 선 줄이기·겹침 비율, 지나는 점(회전 뒤·긴 직선·지그재그·한도), 즐겨찾는 경로 정리
node test/e2e-history.js   # 실제 안내 주행 → 주행 기록 탭·기록 보기 → 즐겨찾는 경로 등록 → 그 길로 안내(through 요청)·이탈·백업
node test/e2e-install.js   # 홈 화면에 추가: 카카오톡(안드로이드·아이폰)·라인·네이버 앱 안, 크롬(설치 창 있음/없음), 아이폰, 삼성 인터넷, 설치된 앱, 앱 주소 보내기, 미리보기 태그
node test/e2e.js phone   # 가짜 네트워크로 전체 흐름(스크린샷: test/out)
node test/e2e2.js        # 내 장소 등록·길게 누르기·경유지·백업
node test/e2e-web.js     # 웹사이트에 올린 상황(EUC-KR 헤더·서비스 워커·홈 화면 정보·파일로 연 경우)
node test/e2e-sw.js      # 서비스 워커와 같은 사이트의 PPT 편집기(docs/ppt): 예전 판에서 넘어올 때 캐시 정리, 끊긴 인터넷
node test/e2e-ko.js      # 검색 결과·저장된 장소가 한국어로 나오는지(영문 저장분 한 번 고치기)
node test/e2e-search.js  # 아파트·주소 검색어 줄이기, 브이월드 인증키(가짜 서버)로 장소·도로명 주소·좌표→주소, 틀린 키
node test/e2e-here.js    # 현재 위치 저장(즐겨찾기·집), 이름·메모로 찾기, 메모 고치기, 위치 권한 없을 때
node test/e2e-walk.js    # 차량↔도보 전환, 도보 요청·카드·계단 피하기, 모의 걷기 화면·안내, 기본 이동 방법
node test/e2e-sheet.js   # 아래 목록 손가락 끌기(실제 터치 입력): 접기·펼치기·튕기기·옆으로 밀기·누르기
node tools/icons.js      # 앱 아이콘 다시 만들기
node tools/og.js         # 링크 미리보기 그림(src/web/og-image.png)
node test/cams-real.js   # 실제 카메라 자료 복원·구간단속 짝 점검
```
